# 7. Enterprise Security & Governance Architecture

## 7.1 Multi-Layered Security Strategy
As an operating system handling financial, legal, and operational intelligence, the MIR-Ecosystem must adhere to strict enterprise security and GDPR compliance.

### The 4 Pillars of Security
1. **Identity & Access (IAM)**: Strict verification of who is asking.
2. **Tenant Isolation**: Ensuring data never bleeds between subsidiaries or clients.
3. **AI Execution Policies**: Protecting against prompt injection and hallucinated destruction.
4. **Data at Rest & In Transit**: Encryption and Auditability.

## 7.2 Authentication & Authorization (RBAC / ABAC)

### Authentication
- Uses **JWT (JSON Web Tokens)** for stateless session management.
- Supports **OAuth2 / OIDC** for Enterprise SSO (Single Sign-On).

### Authorization (RBAC)
Roles are scoped by Tenant (Organization).
- `Super_Admin`: MIR Enterprises root access.
- `Org_Admin`: Admin for a specific subsidiary (e.g., MIR Clothing).
- `Financial_Controller`: Can approve tax submissions generated by Agent 1.
- `Viewer`: Read-only access to dashboards.

## 7.3 AI Security & Prompt Protection

### 1. The Human-in-the-Loop (HITL) Policy
Agents (specifically Agent 1 and Agent 2) are **NEVER** allowed to perform destructive or legally binding actions automatically. 
- *Allowed (Auto)*: Scraping BOE, drafting a risk report, calculating predicted taxes.
- *Blocked (Requires Approval)*: Submitting Modelo 303, executing a bank transfer, emailing a client.

### 2. Prompt Injection Defense
All inputs from users that go to the LLMs are sanitized and passed through a "System Prompt Firewall" layer to ensure bad actors cannot manipulate the Agent into revealing corporate secrets.

## 7.4 Network & Infrastructure Security
- **API Protection**: Rate limiting via Redis to prevent DDoS and API abuse.
- **Secrets Management**: HashiCorp Vault or AWS Secrets Manager for storing LLM API keys, Database credentials, and Stripe keys. Never stored in `.env` in production.
- **WAF**: Cloudflare Web Application Firewall blocking malicious traffic before it hits the Kubernetes ingress.

## 7.5 GDPR & Compliance
- **Right to be Forgotten**: Hard deletion scripts for user data.
- **Data Minimization**: Agents are instructed to summarize and drop PII (Personally Identifiable Information) when storing generic semantic memory.
- **Audit Logs**: Every prompt, agent decision, and database mutation is logged immutably.
